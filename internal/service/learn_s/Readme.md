对于**辅助教学资源**（如 PDF、视频、PPT、音频、图片等）的存储方案**

> ✅ **将资源存到专门的存储系统（如对象存储 OSS/S3），服务端只保存 URL 或资源标识符。**

---

#### 1. **流量卸载（Offload Traffic）**
- 视频/PDF 等大文件直接由 **CDN + OSS** 提供，**不经过你的应用服务器**。
- 你的 API 服务专注处理业务逻辑（如权限校验、记录学习行为），不会被文件下载拖垮。

#### 2. **天然支持高并发**
- 一个热门课程视频可能被万人同时观看。
- 对象存储 + CDN 可轻松应对，而自建服务需集群 + 负载均衡 + 缓存，成本剧增。

#### 3. **灵活的访问控制**
- 使用 **预签名 URL（Signed URL）** 实现：
  ```go
  // 用户请求资源 → 后端验证权限 → 生成 5 分钟有效的 OSS 临时链接 → 返回给前端
  // 前端直接从 OSS 下载，无需经过你
  ```
- 既安全（链接有时效、可限制 IP/User-Agent），又高效。

#### 4. **节省带宽成本**
- 应用服务器通常按固定带宽计费（贵）；
- OSS + CDN 按实际流出流量计费（便宜，且有免费额度）。

#### 5. **易于集成多媒体处理**
- 阿里云 OSS + 媒体处理（MPS）、腾讯云 CI 等可自动：
  - 转码视频（H.264 → H.265）
  - 生成缩略图
  - 抽取 PPT 封面
  - 敏感内容审核

### ✅ 最佳实践建议

1. **数据库只存元数据**  
   ```json
   {
     "id": 123,
     "title": "形式语言与自动机课件",
     "file_key": "materials/cs/compiler_lecture_v3.pdf", // OSS 中的路径
     "size": 4582910, // 可选
     "mime_type": "application/pdf"
   }
   ```

2. **上传流程（不暴露给用户，系统内部人员操作）**  
   - 前端请求 `/api/upload/presigned-url?filename=xxx.pdf`
   - 后端验证权限后，调用 OSS SDK 生成**上传预签名 URL**
   - 前端直传 OSS（不经过你的服务器）

3. **下载流程**  
   - 前端请求 `/api/materials/123/download`
   - 后端验证权限，返回**下载预签名 URL**
   - 前端跳转或发起下载

4. **使用 CDN 加速（可选）**  
   绑定自定义域名 + HTTPS + CDN，提升全球访问速度。
