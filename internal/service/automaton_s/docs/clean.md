# 自动机清理

## 算法概述
清理自动机中的无效状态和不可达状态,优化自动机结构。

## 清理内容

### 1. 移除不可达状态
从初始状态出发,通过 BFS/DFS 找到所有可达状态,移除不可达状态。

### 2. 移除无效符号
移除未使用的输入符号(不在任何转移中出现)。

### 3. 移除无效接受状态
移除不可达的接受状态。

### 4. 优化转移函数
只保留起点和终点都可达的转移。

## 算法步骤

### Step 1: 计算 ε-闭包缓存
为每个状态计算其 ε-闭包,用于后续可达性分析。

### Step 2: 计算可达状态
1. 从初始状态的 ε-闭包开始
2. BFS 遍历所有可达状态
3. 记录使用的输入符号

### Step 3: 重建自动机
1. States: 只保留可达状态
2. Alphabet: 只保留使用的符号(排除 ε)
3. AcceptingStates: 只保留可达的接受状态
4. Transitions: 只保留起点和终点都可达的转移

## 时间复杂度
- O(n + m) (n 为状态数, m 为转移数)

## 空间复杂度
- O(n) (存储可达状态集合)

## 应用场景
- 自动机预处理
- 优化存储空间
- 提高匹配效率

## 参考实现
- 文件: `automaton_s/clean.go`
- 函数: `Cleanup()`

## 示例
输入自动机:
```
States: {q0, q1, q2, q3, q4}
Alphabet: {a, b, c}
Transitions:
  q0 --a--> q1
  q1 --b--> q2
  q2 --a--> q3
  q3 --c--> q3  // c 未在其他地方使用
  q4 --a--> q4  // q4 不可达
Initial: q0
Accepting: {q3, q4}  // q4 不可达
```

输出清理后的自动机:
```
States: {q0, q1, q2, q3}
Alphabet: {a, b}
Transitions:
  q0 --a--> q1
  q1 --b--> q2
  q2 --a--> q3
  q3 --a--> q3
Initial: q0
Accepting: {q3}
```
