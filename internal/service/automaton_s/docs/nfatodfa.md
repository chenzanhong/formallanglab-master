# NFA 确定化 - 子集构造法

## 算法概述
将非确定性有限自动机(NFA)转换为等价的确定性有限自动机(DFA)。

## 核心思想
通过计算 ε-闭包和状态集合的转移,将 NFA 的多状态转移转换为 DFA 的单状态转移。

## 算法步骤

### 1. 计算 ε-闭包
从某个状态出发,通过 ε 转移能到达的所有状态的集合。

```
ε-Closure(q) = {q} ∪ {p | q →ε ... →ε p}
```

### 2. 子集构造主循环
1. 初始状态: NFA 初始状态的 ε-闭包
2. 对每个未处理的状态集合 S 和每个输入符号 a:
   - 计算 S 在 a 下的转移: move(S, a)
   - 计算转移后的 ε-闭包: ε-Closure(move(S, a))
   - 如果是新状态集合,加入队列
3. 重复直到队列为空

### 3. 确定接受状态
如果状态集合中包含 NFA 的任何接受状态,则该 DFA 状态为接受状态。

## 时间复杂度
- 状态数: O(2^n) (n 为 NFA 状态数)
- 时间复杂度: O(n * 2^n) (最坏情况)

## 空间复杂度
- O(2^n) (存储所有状态集合)

## 应用场景
- 正则表达式引擎实现
- 编译器词法分析器生成
- 形式语言理论验证

## 参考实现
- 文件: `automaton_s/nfatodfa.go`
- 函数: `NFAToDFA()`, `NFAToDFAWithProcess()`

## 示例
输入 NFA:
```
States: {q0, q1, q2}
Alphabet: {a, b}
Transitions:
  q0 --a--> {q0, q1}
  q0 --b--> {q1}
  q1 --ε--> q2
  q2 --a--> q2
Initial: q0
Accepting: {q2}
```

输出 DFA:
```
States: {{q0}, {q0,q1}, {q1,q2}, {q2}}
Alphabet: {a, b}
Transitions:
  {q0} --a--> {q0,q1}
  {q0} --b--> {q1,q2}
  {q0,q1} --a--> {q0,q1,q2}
  ...
Initial: {q0}
Accepting: {{q1,q2}, {q0,q1,q2}, {q2}}
```
