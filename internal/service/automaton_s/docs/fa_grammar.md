# 自动机转文法

## 概述
将有限自动机转换为等价的正则文法(右线性文法)。

## 转换方法

### 标准转换 (右线性文法)

给定 NFA M = (Q, Σ, δ, q₀, F),构造右线性文法 G = (V, Σ, P, S):

#### 1. 非终结符集合
```
V = Q (每个状态是一个非终结符)
```

#### 2. 终结符集合
```
Σ 不变
```

#### 3. 开始符号
```
S = q₀ (初始状态)
```

#### 4. 产生式规则
对每条转移 δ(qᵢ, a) ∋ qⱼ:
```
qᵢ → a qⱼ
```

对每个终态 q_f ∈ F:
```
q_f → ε
```

## 算法步骤

### Step 1: 初始化文法
```
NonTerminals = States
Terminals = Alphabet
StartSymbol = InitialState
```

### Step 2: 添加转移产生式
对每条转移 (qᵢ, a, qⱼ):
```
添加产生式: qᵢ → a qⱼ
```

### Step 3: 添加 ε 产生式
对每个接受状态 q_f:
```
添加产生式: q_f → ε
```

## 时间复杂度
- O(m) (m 为转移数)

## 空间复杂度
- O(m) (产生式数量)

## 注意事项
- 转换是保语言的:L(M) = L(G)
- 生成的文法是右线性的
- ε-转移对应单位产生式

## 应用场景
- 自动机分析
- 文法生成
- 教学演示

## 参考实现
- 文件: `automaton_s/fa_grammar.go`
- 函数: `FAToGrammar()`

## 示例
```
NFA:
  q0 --a--> q1
  q1 --b--> q1
  q1 --ε--> q2

转换为文法:
  NonTerminals: {q0, q1, q2}
  Terminals: {a, b}
  StartSymbol: q0
  
  产生式:
    q0 → a q1
    q1 → b q1
    q1 → ε
    q2 → ε (如果 q2 是接受状态)
```

## 逆转换
文法 → 自动机:
- 右线性文法 G = (V, Σ, P, S) → NFA
- 每个非终结符是一个状态
- 每个产生式 A → aB 对应转移 A --a--> B
- 每个产生式 A → ε 对应 A 是接受状态
