## 算法分类

### 1. 自动机算法 (11个)

#### 基础操作
- **NFA确定化**: 子集构造法 - 将NFA转换为等价的DFA
- **DFA最小化**: Hopcroft算法 - 将DFA转换为最少状态的等价DFA
- **自动机清理**: 移除不可达状态和无效符号
- **DFA完备化**: 添加陷阱状态确保每个状态都有确定的转移
- **自动机验证**: 验证自动机的有效性

#### 高级操作
- **字符串识别**: 判断字符串是否能被自动机接受
- **自动机等价性检查**: 判断两个自动机是否接受相同语言
- **自动机转正则表达式**: 状态消除法
- **自动机转文法**: 右线性文法转换
- **DFA补集**: 构造接受补集语言的DFA
- **生成示例字符串**: 生成可接受和不可接受的字符串示例

### 2. 文法算法 (8个)

#### 基础操作
- **文法验证**: 验证文法的有效性
- **文法类型判定**: Chomsky分类(0、1、2、3型)
- **文法化简**: 去除无用符号和冗余产生式

#### 高级操作
- **文法识别与分析**: BFS推导、LL(1)分析、LR(0)分析
- **文法二义性检查**: 检查文法是否存在二义性
- **文法等价性检查**: 判断两个文法是否等价
- **文法示例字符串生成**: 生成可推导和不可推导的字符串
- **文法转自动机**: 正则文法到有限自动机的转换

### 3. 正则表达式算法 (5个)

#### 基础操作
- **正则表达式验证**: 验证正则表达式语法
- **正则表达式识别**: 判断字符串是否匹配正则表达式
- **正则表达式等价性检查**: 判断两个正则表达式是否等价

#### 高级操作
- **正则表达式示例字符串生成**: 生成可匹配和不可匹配的字符串
- **正则表达式转自动机**: Thompson构造法

## 算法复杂度

### 时间复杂度
- **最优**: O(n) - 正则表达式验证、识别
- **平均**: O(n^2) - 文法分析、自动机操作
- **最坏**: O(2^n) - NFA确定化、等价性检查

### 空间复杂度
- **最优**: O(1) - 验证操作
- **平均**: O(n) - 大多数算法
- **最坏**: O(2^n) - NFA确定化
