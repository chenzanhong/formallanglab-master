# 文法化简

## 概述
对文法进行化简,去除无用符号和冗余产生式。

## 化简内容

### 1. 去除不可派生的变量
- 不能推导出终结符串的变量
- 从右向左迭代计算可派生变量集

### 2. 去除不可达符号
- 从起始符号无法到达的变量和终结符
- 从左向右迭代计算可达符号集

### 3. 去除空产生式 (ε-产生式)
- 除 S → ε 外,去除所有 A → ε
- 计算可空变量集,生成所有可能的产生式

### 4. 去除单一产生式 (单位产生式)
- 去除 A → B 形式的产生式
- 计算单位产生式闭包

## 算法步骤

### Step 1: 去除不可派生变量
```
NEWV = { A | A → w ∈ P, w ∈ T* }
迭代: NEWV = OLDV ∪ { A | A → α ∈ P, α ∈ (T ∪ OLDV)* }
```

### Step 2: 去除不可达符号
```
从 S 出发,迭代计算可达变量和终结符
```

### Step 3: 去除空产生式
```
计算可空变量集 U
对每个产生式 A → α,生成所有子集
```

### Step 4: 去除单一产生式
```
计算单位产生式闭包
构建新的产生式集合
```

## 时间复杂度
- O(n*m) (n 为产生式数量, m 为产生式平均长度)

## 空间复杂度
- O(n)

## 应用场景
- 文法优化
- 分析前预处理
- 教学演示
