# 文法验证

## 验证内容

### 1. 基本有效性检查
- 文法对象非空
- 非终结符集和终结符集都不能为空
- 起始符号必须存在且为非终结符
- 非终结符和终结符集合不能有交集
- 必须至少有一个产生式
- 每个产生式的左部至少包含一个非终结符

## 验证规则

```
1. 文法对象非空
2. 非终结符集合非空
3. 终结符集合非空
4. 起始符号必须是非终结符
5. 非终结符和终结符不能有交集
6. 至少有一个产生式
7. 每个产生式的左部至少包含一个非终结符
8. 所有符号都在符号集合中
```

## 时间复杂度
- O(n*m + k) (n 为产生式数量, m 为产生式平均长度, k 为符号集合大小)

## 空间复杂度
- O(1)

## 应用场景
- 用户输入验证
- 文件加载校验
- 算法执行前的预检查
