# 文法转自动机

## 概述
将正则文法转换为等价的有限自动机。

## 转换方法

### 右线性文法 → NFA

给定右线性文法 G = (V, Σ, P, S),构造 NFA M = (Q, Σ, δ, q₀, F):

#### 1. 状态集合
```
Q = V ∪ {accept} (每个非终结符是一个状态,加一个接受状态)
```

#### 2. 字母表
```
Σ 不变
```

#### 3. 初始状态
```
q₀ = S (开始符号)
```

#### 4. 转移函数
对每条产生式:
- A → aB: δ(A, a) = {B}
- A → a: δ(A, a) = {accept}
- A → ε: A ∈ F

#### 5. 接受状态
```
F = {accept} ∪ {A | A → ε ∈ P}
```

### 左线性文法 → NFA

#### 方法一: 语言反转
1. 反转语言: 左线性文法 G 生成语言 L,其反转语言 L^R 可由右线性文法 G^R 生成
2. 转右线性为 NFA: 用标准方法将 G^R 转换为 NFA M' (识别 L^R)
3. 反转自动机: 将 M' 的起始状态与终态互换,转移方向反转 (识别 L)

#### 方法二: 直接构造 (反向建图)
1. 状态设计: 每个非终结符作为一个状态;新增初始状态 q₀
2. 转移规则:
   - A → Ba: δ(B, a) = {A}
   - A → a: δ(q₀, a) = {A}
   - S → ε: q₀ ∈ F
3. 终态设定: S 对应的状态设为唯一终态

## 时间复杂度
- O(m) (m 为产生式数量)

## 空间复杂度
- O(m) (转移数量)

## 应用场景
- 文法分析
- 自动机生成
- 教学演示

## 参考实现
- 文件: `grammar_s/grammar_fa.go`
- 函数: `RegularGrammarToFA()`, `rightLinearGrammarToFA()`, `leftLinearGrammarToFA()`

## 示例
```
右线性文法: S → aS | b

NFA:
  States: {S, accept}
  Alphabet: {a, b}
  Transitions:
    S --a--> S
    S --b--> accept
  Initial: S
  Accepting: {accept}
```

## 逆转换
自动机 → 文法:
- 每个状态是一个非终结符
- 每条转移 A --a--> B 对应产生式 A → aB
- 每个接受状态 A 对应产生式 A → ε
