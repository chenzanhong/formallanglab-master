# 正则表达式识别

## 概述
判断字符串是否匹配正则表达式。

## 算法思路

### 1. 转换为 Go 正则表达式
```
pattern = "^(?:" + regex + ")$"
```

### 2. 编译正则表达式
```
re, err := regexp.Compile(pattern)
```

### 3. 匹配字符串
```
match := re.MatchString(str)
```

## 特殊情况处理

### 空集
- 不接受任何字符串,包括空串

### 空串 (ε)
- 只匹配空字符串

## 时间复杂度
- 编译: O(n)
- 匹配: O(m) (n 为正则表达式长度, m 为字符串长度)

## 空间复杂度
- O(n) (正则表达式编译后的状态)

## 应用场景
- 字符串匹配
- 词法分析
- 模式匹配

## 参考实现
- 文件: `regex_s/recognize.go`
- 函数: `RegexRecognize()`

## 示例
```
正则表达式: a*b
字符串: "aab"
匹配结果: true

正则表达式: (a|b)*c
字符串: "abac"
匹配结果: false
```
