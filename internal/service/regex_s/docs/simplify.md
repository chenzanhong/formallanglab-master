# 正则表达式化简

## 功能概述

正则表达式化简功能用于将复杂的正则表达式转换为等价的更简洁形式，同时保持其接受的语言不变。

## 化简规则

### 1. Kleene 星号 (*) 化简
- `∅* = ε` - 空集的 Kleene 闭包等于空串
- `ε* = ε` - 空串的 Kleene 闭包等于空串

### 2. 正闭包 (+) 化简
- `∅+ = ∅` - 空集的正闭包等于空集
- `ε+ = ε` - 空串的正闭包等于空串

### 3. 可选操作 (?) 化简
- `∅? = ε` - 空集的可选操作等于空串
- `ε? = ε` - 空串的可选操作等于空串

### 4. 连接操作化简
- `εA = A` - 空串与任何字符串连接等于该字符串
- `Aε = A` - 任何字符串与空串连接等于该字符串
- `∅A = ∅` - 空集与任何字符串连接等于空集
- `A∅ = ∅` - 任何字符串与空集连接等于空集

### 5. 并集操作化简
- `A|∅ = A` - 任何集合与空集的并集等于该集合
- `∅|A = A` - 空集与任何集合的并集等于该集合
- `A|A = A` - 相同集合的并集等于该集合（幂等律）

## 实现原理

### 1. 词法分析
将正则表达式字符串转换为 token 流：
- 字符 token (a-z, A-Z, 0-9)
- 操作符 token (*, +, ?, |, (, ))
- 特殊符号 token (ε, ∅)

### 2. 语法分析
使用递归下降解析器构建抽象语法树 (AST)：
- `parseUnion()` - 解析并集操作（最低优先级）
- `parseConcat()` - 解析连接操作
- `parseAtom()` - 解析原子操作（字符、括号）

### 3. AST 化简
递归遍历 AST，应用化简规则：
- 自底向上化简子节点
- 根据节点类型应用对应的化简规则
- 返回化简后的 AST

### 4. 空语言检测
检查化简后的 AST 是否表示空语言：
- 连接操作：只要有一个子节点是 ∅，结果就是 ∅
- 并集操作：所有子节点都是 ∅，结果才是 ∅
- Kleene 星号和可选操作：永远不是空语言（至少接受 ε）
- 正闭包：如果子节点是 ∅，则是 ∅

### 5. AST 转字符串
将化简后的 AST 转换回正则表达式字符串：
- 根据需要添加括号以保持优先级
- 处理操作符的结合性

## 时间复杂度
- 词法分析：O(n)
- 语法分析：O(n)
- AST 化简：O(n)
- 总体：O(n) (n 为正则表达式长度)

## 空间复杂度
- O(n) (AST 节点数量)

## 应用场景
- 正则表达式优化
- 等价性检查前的预处理
- 自动机转换前的化简
- 教学演示中的表达式简化

## 示例

### 示例 1：Kleene 星号化简
```
输入：(a|∅)*
输出：ε
解释：并集 a|∅ 化简为 a，然后 a* 保持不变，但如果内部是 ∅，则 ∅* = ε
```

### 示例 2：连接化简
```
输入：ε(a|b)
输出：(a|b)
解释：ε 与任何表达式连接等于该表达式本身
```

### 示例 3：空集连接
```
输入：(a|b)∅
输出：∅
解释：任何表达式与空集连接等于空集
```

### 示例 4：复杂化简
```
输入：(∅|ε)*
输出：ε
解释：∅|ε = ε，然后 ε* = ε
```

## 参考实现
- 文件：`regex_s/simplify.go`
- 函数：`SimplifyRegex()`

## 注意事项
1. 化简过程保持语义等价性
2. 支持 ε 和 ∅ 特殊符号
3. 自动处理空白字符（忽略）
4. 对于非法输入会返回错误
5. 化简结果可能不唯一，但保证语义正确
