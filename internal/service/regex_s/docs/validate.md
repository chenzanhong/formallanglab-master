# 正则表达式验证

## 验证内容

### 1. 基本语法检查
- 使用 Go 的 regexp 包进行编译验证
- 检查正则表达式是否合法

### 2. 特殊符号处理
- 支持 ε (空串)
- 支持 ∅ (空集)

## 验证规则

```
1. 正则表达式语法正确
2. 支持的运算符: * + ? | ()
3. 支持的特殊符号: ε, ∅
```

## 时间复杂度
- O(n) (n 为正则表达式长度)

## 空间复杂度
- O(1)

## 应用场景
- 用户输入验证
- 文件加载校验
- 算法执行前的预检查

## 参考实现
- 文件: `regex_s/validate.go`
- 函数: `RegexValidate()`, `RegexValidString()`
